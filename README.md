# skool-comment-agent

An agent skill that drafts Skool comments. It reads the newest public posts of one community while logged out, drafts up to 3 comments in my voice, checks each against a safety checklist, and sends them to me in chat.

Drafts only. It never logs in, posts, comments, likes or replies. I post by hand.

Install in OpenMausBot: Bot → Library → Skills → paste `tariqosmani/skool-comment-agent` → Add, then switch it on.
